* Welcome to BabelHub

This is an org-mode document rendered live in your browser. Edit the source on
the left; the preview updates as you type.

Unlike a static GitHub render, the source blocks below are *runnable* — R runs
client-side via [[https://webr.r-wasm.org][webR]] and Python via [[https://pyodide.org][Pyodide]], so execution costs the
server nothing. The =#+PROPERTY: header-args= lines above set a shared
~:session~ per language, so when you open this file in Emacs the blocks run in
one persistent session too.

** A first computation

#+begin_src R
x <- rnorm(1000, mean = 100, sd = 15)
sprintf("n=%d  mean=%.2f  sd=%.2f", length(x), mean(x), sd(x))
#+end_src

** Output is captured too

#+begin_src R
summary(mtcars$mpg)
#+end_src

** Plots come back too

Anything drawn to R's graphics device is captured and shown inline.

#+begin_src R
hist(rnorm(1000), col = "#2f7d5b", border = "white",
     main = "1000 draws from N(0,1)")
#+end_src

** Python runs too

#+begin_src python
import sys
print("Python", sys.version.split()[0], "in the browser")
print(sum(range(101)))
#+end_src

Because each language shares one session, a later block sees earlier state:

#+begin_src python
xs = [x * x for x in range(10)]
xs
#+end_src

Imported packages (numpy, pandas, matplotlib, …) auto-load on first use, and
matplotlib figures are captured inline:

#+begin_src python
import matplotlib.pyplot as plt
import numpy as np
plt.plot(np.cumsum(np.random.randn(200)))
plt.title("a random walk")
plt.show()
#+end_src
